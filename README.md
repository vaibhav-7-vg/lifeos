# LifeOS PWA

## Included
- Mobile-first PWA UI
- Home command center
- Tasks, reminders, events, lists/notes
- Money: income, expenses, lending, goals, tracked assets
- People and ConnectCircle-style activity requests
- Documents and expiry dates
- Assets and warranties
- Receipts
- Safety Check for suspicious messages
- Local data insights
- Local LifeOS assistant
- Export/reset data
- Offline service worker

## Important
This is a complete functional MVP/foundation, but not a production-grade global SaaS yet. Data is stored locally in the browser. Do not store sensitive identity documents or financial secrets until encrypted storage, authentication, secure sync, backup recovery, and a proper privacy/security architecture are added.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Commit changes.
4. GitHub → Settings → Pages.
5. Deploy from the `main` branch and `/ (root)`.
6. Open the generated HTTPS URL on your phone.
7. Browser menu → Add to Home screen / Install app.

For PWA features, use HTTPS (GitHub Pages provides it).
